# Etapa 10 — Ensaio geral cronometrado + kit 🔜

!!! warning "Planejada — o drill final antes de fechar a mala"

**O drill:** desconectar TUDO, guardar como se fosse viajar, e cronometrar do zero: cabo → `nmcli con up go2` → pings → SSH sem senha → `docker start -ai casa` → tópicos do robô no `ros2 topic list` → robô levanta via SDK → bônus: `escola` com router Zenoh + talker/listener. **Meta: < 10 minutos. Repetir 2×**, anotando gargalos.

**Kit físico:** 2 cabos ethernet, carregador do Go2 + 2 baterias, controle, roteador de viagem já configurado, adaptador USB-ethernet reserva (lembrando: [o perfil `go2` funciona com qualquer um](01-rede-go2.md)), régua + adaptador de tomada EU, ferramentas, fita, powerbank, cheatsheet impresso.

**Burocracia:** notebook Linux ✔; guest agreement se assina presencialmente na segunda (levar documento); fórum RimA: `forum.roboter-im-alltag.org`.
